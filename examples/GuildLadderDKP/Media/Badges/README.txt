Badge artwork (32-bit TGA, 64x64): IronAttendance, Veteran, BigSpender, TopBid, FlaskMaster, Collector.
Make them from PNGs with tools/make_badge_tga.py, then make sure the badge has custom = true in D.BADGE_ART (Core.lua).
Window art (menu icons, crests, wordmark, plaques) is in Media\Menu and Media\Brand, built with tools/make_ui_art.py.
