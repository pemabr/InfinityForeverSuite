# PluribusDKP Item Filtering - Quick Reference

## Tax System - Filtering Items

### Toggle Mode
```
/dkp tax whitelist mode on    -- Only tax whitelisted items
/dkp tax whitelist mode off   -- Tax all except blacklisted items (default)
```

### Whitelist (Only these items get taxed)
```
/dkp tax whitelist add 2589      -- Add Mithril Ore
/dkp tax whitelist remove 2589   -- Remove from whitelist
/dkp tax whitelist list          -- Show all whitelisted items
/dkp tax whitelist clear         -- Delete entire whitelist
```

### Blacklist (These items are excluded from taxation)
```
/dkp tax blacklist add 2589      -- Blacklist vendor trash
/dkp tax blacklist remove 2589   -- Remove from blacklist
/dkp tax blacklist list          -- Show all blacklisted items
/dkp tax blacklist clear         -- Delete entire blacklist
```

## Guild Bank Donations - Filtering Items

### Toggle Mode
```
/dkp donations whitelist mode on    -- Only these items award DKP
/dkp donations whitelist mode off   -- All items award DKP except blacklisted
```

### Whitelist (Only these items award DKP)
```
/dkp donations whitelist add 1234    -- Whitelist epic item
/dkp donations whitelist remove 1234 -- Remove from whitelist
/dkp donations whitelist list        -- Show all whitelisted items
/dkp donations whitelist clear       -- Delete entire whitelist
```

### Blacklist (These items don't award DKP)
```
/dkp donations blacklist add 2589      -- Blacklist vendor trash
/dkp donations blacklist remove 2589   -- Remove from blacklist
/dkp donations blacklist list          -- Show all blacklisted items
/dkp donations blacklist clear         -- Delete entire blacklist
```

## Finding Item IDs

**Method 1:** Hover over item link in chat and look for `|Hitem:ITEMID:`

**Method 2:** Shift+click item into chat, then extract ID from the link

**Method 3:** Use WoW database:
- https://classicdb.ch/ (for Classic)
- https://www.vanillawowdb.com/ (for Vanilla)

## Common Use Cases

### Scenario: "Tax only crafting materials, not equipment"
```
/dkp tax whitelist mode on
/dkp tax whitelist clear
/dkp tax whitelist add 2320    -- Mithril Ore
/dkp tax whitelist add 2321    -- Mithril Bar
/dkp tax whitelist add 2771    -- Thorium Ore
-- Add more crafting material IDs as needed
```

### Scenario: "Don't tax vendor trash"
```
/dkp tax whitelist mode off
/dkp tax blacklist clear
/dkp tax blacklist add 2589    -- Blasted Boar Meat
/dkp tax blacklist add 2590    -- Ravasaur Hide
-- Add more trash items to blacklist
```

### Scenario: "Only reward donations of epic/legendary items"
```
/dkp donations whitelist mode on
/dkp donations whitelist clear
/dkp donations whitelist add 1234    -- Some epic item
/dkp donations whitelist add 5678    -- Some legendary item
-- Add more epic/legendary IDs
```

## Default Behavior

- **Whitelist mode OFF** (blacklist mode) - All items processed unless blacklisted
- **Empty blacklist** - All items are processed
- **Empty whitelist** - NO items are processed when in whitelist mode
- Filters persist across game sessions
- Filters are stored per-guild

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Item still being taxed after blacklisting | Verify you're in blacklist mode: `/dkp tax whitelist mode off` |
| No items being taxed | If in whitelist mode, check if whitelist is empty: `/dkp tax whitelist list` |
| Can't remember which mode is active | Type `/dkp tax whitelist mode` without arguments to see current mode |
| Wrong item ID | Double-check the item link or use WoW database to verify ID |
| Filter list too long | Consider using the opposite mode (whitelist vs blacklist) |
