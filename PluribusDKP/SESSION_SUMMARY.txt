================================================================================
API FUNCTIONS
================================================================================

Both TaxSystem and GuildBankDonations provide:

Filtering Management:
  - SetWhitelistMode(enabled)        -- Toggle between modes
  - WhitelistItem(itemId)             -- Add to whitelist
  - UnwhitelistItem(itemId)           -- Remove from whitelist
  - BlacklistItem(itemId)             -- Add to blacklist
  - UnblacklistItem(itemId)           -- Remove from blacklist
  - GetWhitelist()                    -- Get all whitelisted items
  - GetBlacklist()                    -- Get all blacklisted items
  - ClearWhitelist()                  -- Delete entire whitelist
  - ClearBlacklist()                  -- Delete entire blacklist

Checking:
  - ShouldTaxItem(itemId) [TaxSystem only]       -- Check if taxed
  - ShouldAwardDKP(itemId) [GuildBankDonations]  -- Check if rewarded

GuildBankDonations additional:
  - SetItemRewardMode(mode)           -- "value" or "rarity"

================================================================================
TECHNICAL DETAILS
================================================================================

Implementation Type: Hash table-based filtering
Performance: O(1) lookup time per item
Memory: ~1 byte per item (negligible for typical use)
Recommended Limit: Under 10,000 items per filter
Maximum Sustainable: ~50,000 items (~50KB RAM)

Filtering Logic:
  Blacklist Mode (default):
    if item in blacklist:
      skip
    else:
      process

  Whitelist Mode:
    if item in whitelist:
      process
    else:
      skip

Data Storage:
  Items stored as: {itemId = true, ...}
  Mode stored as: whitelistMode = boolean
  All data saved in SavedVariables for persistence

Event System:
  - whitelist_mode_changed
  - item_whitelisted
  - item_unwhitelisted
  - item_blacklisted
  - item_unblacklisted
  - whitelist_cleared
  - blacklist_cleared
